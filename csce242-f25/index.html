P. Elena Maddox's Assignment Portal for CSCE 242: Web Applications

USC's Academic Bulletin Description of the course states that CSCE 242 is a course which teaches "Web technologies to support client-server computing" and "Implementation of client-server applications."

Instructor Portia Plante's syllabus explains that "Firstly, students will utilize HTML and CSS to design the front-end of a website; matching a given specification. Secondly, they will use JavaScript to add functionality to their website. Lastly, they will learn to utilize node and server side JavaScript to store and retrieve data from a server."
