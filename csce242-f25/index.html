P. Elena Maddox's Assignment Portal for CSCE 242: Web Applications

USC's Academic Bulletin Description of the course states that CSCE 242 is a course which teaches "Web technologies to support client-server computing" and "Implementation of client-server applications."

Instructor Portia Plante's syllabus explains that "Firstly, students will utilize HTML and CSS to design the front-end of a website; matching a given specification. Secondly, they will use JavaScript to add functionality to their website. Lastly, they will learn to utilize node and server side JavaScript to store and retrieve data from a server."

Assignments

  1. Assignment 1-Basic HTML

    Assignment 1 covers the basics of HTML coding and formatting using only the HTML language, including headers, images, and links.

  2. Assignment 2-Basic CSS

    Assignment 2 covers the basics of styling websites using the CSS language, including coding practices for ensuring good style sheet structure.

  3. Assignment 3-Page Layout

    Assignment 3 covers how to use flexboxes and structure elements in HTML to improve the appearance and versatility of web pages.

  1. Assignment 4-CSS Recreate

    Assignment 4 involves recreating a page on the UofSC website using flexboxes and various other new concepts in CSS.

  2. Assignment 5- Javascript Intro

    Assignment 5 involves recreating a page with columns using Javascript, like to add functions to make text appear when a column is clicked.

  3. Assignment 6- Conditionals

    Assignment 6 involves recreating a page regarding conditionals and if statements, like to add functions to make a div appear when a nav item is clicked and the other div is hidden.

  1. Assignment 7- Loops

    Assignment 7 involves recreating a page regarding loops-making css art appear repetitively, as well as changing the background by time of day.

  2. Assignment 8- Arrays

    Assignment 8 involves creating associative arrays that loop on load, having information show on images, and having a popup show when the image is clicked.

  3. Assignment 9- Classes

    Assignment 9 involves creating associative a class that loops on load to generate class items, as well as access class item data to display the data and change styles.

  1. Assignment 10- Server Side HelloWorld

    Assignment 10 involves creating a server app that says "Hello World" using Node, Render, and Github.

Project

  1. Part 1- Project Topic

    Part 1 of the project involved selecting a topic for the website to be built, picking a website name and its pages, and writing a brief description of the concept.

  2. Part 2- Wireframe

    Part 2 of the project involved creating a website wireframe using MockITT and embedding it in the assignment portal.

  3. Part 3- HTML and CSS

    Part 3 of the project involved creating a website's base for HTML and CSS based on the MockITT wireframe created in part 2.

  1. Part 4- HTML and CSS

    Part 3 of the project involved finding images and writing paragraphs to replace dummy images and lorem ipsum paragraphs.

  2. Part 5- Images and Text P2

    Part 5 of the project involved improving the appearances of the website, especially pertaining to the text and images added in part 4.

  3. Part 6- Images and Text P2

    Part 6 of the project involved adding JSON functionality to the website, allowing the items to load in by accessing a JSON file's data.

  1. Part 7- Contact Form, Javascript
